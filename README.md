# Sistema de Reservas de Eventos

Aplicación web que permite a los usuarios reservar eventos de forma rápida y sencilla, evitando reservas duplicadas mediante almacenamiento local.

## Funcionalidades principales

- Crear una nueva reserva indicando nombre, tipo de evento, fecha y hora.
- Mostrar la lista de reservas existentes.
- Cancelar una reserva ya creada.
- Validar y evitar reservas duplicadas para el mismo evento, fecha y hora.
- Persistencia de datos en el navegador usando `localStorage`.
